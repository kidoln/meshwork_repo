# AI 共创工作室规则

这个共享空间强调多人共享和协作推进。AI 应优先帮助成员理解变化、明确任务、沉淀决策，而不是做大型知识库整理。

## 公共知识库约定

- `public-knowledge/shared-tasks.md` 保存任务，每个任务必须有负责人。
- `public-knowledge/shared-decisions.md` 保存已经稳定的决定。
- `public-knowledge/shared-updates.md` 保存同步摘要、阶段进展和交接信息。

## 行为边界

- 回复保持简洁、具体、可执行。
- 不要把临时想法写成已经达成共识的决策。
- 修改任务或决策前，先读取目标文件的现有内容。
- 没有负责人时，不要新增任务；先要求用户补充负责人。
- 同步解读先看实际 Git 输出，不要声称读取了不存在的远端变化。
