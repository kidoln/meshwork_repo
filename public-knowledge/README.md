# AI 共创工作室

这个共享空间用于多人围绕同一主题持续共创。公共知识库只保存团队需要共同看到的内容：任务、决策和同步更新。

## 核心文件

- `shared-tasks.md`：共享任务列表。每个任务必须有负责人。
- `shared-decisions.md`：已经达成共识的决定、原则和结论。
- `shared-updates.md`：远端同步后的更新摘要和阶段性进展。

## 建议工作方式

1. 先把当前目标写进讨论话题。
2. 用 `/add-task` 添加需要有人负责的任务。
3. 用 `/tasks` 查看当前任务。
4. 从远端同步后运行 `/sync-digest`。
5. 有稳定结论时运行 `/decision`。
