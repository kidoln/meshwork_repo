# 绘图信息

## 常用绘图工具

### Python 绘图库
- **Matplotlib** - Python 最基础的绘图库，支持各种2D和3D图表
- **Seaborn** - 基于Matplotlib的统计可视化库，提供更美观的默认样式
- **Plotly** - 交互式图表库，支持在线分享和动态更新
- **Bokeh** - 交互式可视化库，适合大数据集
- **Altair** - 基于Vega-Lite的声明式可视化库

### 其他语言工具
- **R语言** - ggplot2 (基于图形语法)
- **JavaScript** - D3.js, Chart.js, ECharts
- **Julia** - Plots.jl, Gadfly.jl

## 常用图表类型

### 统计图表
- **散点图** - 显示两个变量之间的关系
- **折线图** - 显示趋势变化
- **柱状图** - 比较不同类别的数值
- **饼图** - 显示占比关系
- **箱线图** - 显示数据分布和异常值
- **直方图** - 显示数据频率分布

### 科学图表
- **热力图** - 显示矩阵数据
- **等高线图** - 显示三维数据
- **3D曲面图** - 显示复杂函数关系
- **矢量场图** - 显示流向和强度

### 专业图表
- **桑基图** - 显示流向和转化
- **树状图** - 显示层级关系
- **网络图** - 显示关系网络
- **地理地图** - 显示空间数据

## 绘图最佳实践

### 设计原则
1. **简洁性** - 避免不必要的装饰，突出数据本身
2. **清晰性** - 使用合适的标签、标题和图例
3. **准确性** - 选择合适的图表类型和比例尺
4. **一致性** - 在系列图表中保持样式一致

### 颜色选择
- **对比色** - 用于区分不同类别
- **渐变色** - 用于显示连续变化
- **色盲友好** - 考虑色盲人群的阅读体验
- **打印友好** - 确保黑白打印时仍可区分

### 标签和注释
- **标题** - 清晰描述图表内容
- **轴标签** - 说明变量含义和单位
- **图例** - 解释符号和颜色的含义
- **注释** - 标注重要数据点和趋势

## 示例代码

### Matplotlib 基础示例
```python
import matplotlib.pyplot as plt
import numpy as np

# 创建数据
x = np.linspace(0, 10, 100)
y = np.sin(x)

# 创建图表
plt.figure(figsize=(10, 6))
plt.plot(x, y, label='sin(x)')
plt.xlabel('x')
plt.ylabel('y')
plt.title('正弦函数图像')
plt.legend()
plt.grid(True)
plt.show()
```

### Seaborn 统计图表示例
```python
import seaborn as sns
import pandas as pd

# 创建示例数据
data = pd.DataFrame({
    'category': ['A', 'B', 'C', 'D'] * 25,
    'value': np.random.randn(100)
})

# 创建箱线图
plt.figure(figsize=(10, 6))
sns.boxplot(x='category', y='value', data=data)
plt.title('类别数值分布')
plt.show()
```

## 文件格式和导出

### 常用格式
- **PNG** - 通用位图格式，适合网页
- **PDF** - 矢量格式，适合论文和打印
- **SVG** - 矢量格式，可编辑
- **EPS** - 矢量格式，适合学术出版

### 分辨率设置
- 网页显示：72-96 DPI
- 打印：300 DPI
- 学术出版：600 DPI 或更高
